# Design

Design work for Flowstate lands here (D11). It is the input to the
specs in `docs/spec/`; once a screen's spec is written, the spec is what code follows.

| Folder | What goes in | Format |
|---|---|---|
| `wireframes/` | Hand or digital wireframes, one file per screen | PNG/JPG/PDF, named `NN-screen-name.png` |
| `concept/` | Concept theory: the idea behind how Flowstate works and why | Markdown (`concept.md`) |
| `references/` | Software references: products, screens or patterns to learn from, with what to take and what not to | Markdown + screenshots |
| `paper/` | Final designs exported from Paper | PNG/PDF exports + the Paper link in `paper/README.md` |

Coordinator screens only: carers use the shared Aultrum carer app (D10).

When adding a file, say in one line what it is and which screen or function it
belongs to, so any tool can pick it up without the chat it came from.
